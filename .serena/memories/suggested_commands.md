# Suggested Commands

## Run simulation
```bash
python main.py
```

## Run tests
```bash
python -m pytest tests/ -v
```

## Run specific test file
```bash
python -m pytest tests/test_engine_mechanics.py -v
```

## Run benchmarks
```bash
python -m benchmark.run_all
```

## Type checking
```bash
pyright
```

## Linting / formatting
```bash
ruff check .
ruff format .
```

## System utilities (Darwin)
- `git` for version control
- `ls`, `find`, `grep` — standard Darwin variants
